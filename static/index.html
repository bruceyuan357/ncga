           About
          
    把每一字，都揉回它该有的乡音
    
          
    地道中文是一个把任意中文文本按方言重新组织语气、词汇与句式的小工具。
          它不替换主题，只换说法——希望你写出去的话，读起来像本地朋友亲口讲的。

     常见疑问
    
            
    
              它能完美还原我家乡的口音吗？
              
    它努力还原"写下来的方言味儿"，但口音、声调得靠耳朵。所以提供了朗读按钮做参考。
    
            
    
            
    
              为什么闽南话标成"试用版"？
              
    闽南话与普通话语法、词汇差异极大，AI 训练语料较少，输出会比其他方言不稳定，仅供参考体验。我们不提供闽南语 TTS（避免普通话发音误读）。
    
            
    
            
    
              粤语 / 闽南语为什么是繁体？
              
    这两种语言长期使用繁体汉字书写，许多本字（如"係、唔、㗎、毋"）在简体里没有通用对应。
    
            
    
            
    
              历史记录会上传吗？
              
    不会。所有历史与偏好都只存在你的浏览器本地。
    
            
    
            
    
              "已降级"标签是什么意思？
              
    当 LLM 不可用（无 API key、网络故障、返回格式异常）时，本工具会回退到本地启发式重写——只做有限的词替换，效果远不如 LLM。"已降级"角标提醒你：当前这条结果不可作为最终成品使用。
