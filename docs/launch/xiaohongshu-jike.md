# 小红书 / 即刻 发布草稿

**小红书版：**

标题：给爸妈发消息终于不像公文了🥹 这个方言改写器是我今年最满意的作品

正文：
有没有人和我一样，给上海奶奶发微信，打出来的字总觉得「太书面」？
「奶奶我今天去超市买东西」—— 没错，但奶奶自己不这么说话。

做了个小工具叫「地道中文」：把书面普通话改成十种方言的真实口感。
北京话的「您猜怎么着」、川渝的「巴适」、上海话的「老好额」、粤语的
「咁先至啱」—— 不是简单换词，是整句的语气、语序、句末助词都到位。

而且每种方言的地道程度是有考试分数的📊 改差了会被自动拦下来重写，
不是随便生成糊弄人。

🔑 可以不用注册：设置里粘自己的 DeepSeek key 就能用全部功能
🏠 所有记录只存在你自己浏览器里
📜 开源免费（MIT），会点电脑就能自己部署

评论区告诉我你是哪里人，我来加你的家乡话（现在江淮话还需要更多语料，
江淮的朋友在哪里🙋）

**即刻版：**

给「地道中文」加了自带 Key 功能之后，它终于可以公开发了。

一个把书面普通话改写成十种方言口感的小应用。三个自认为做对的设计：

1. 方言质量做成评测门禁而不是玄学：golden set + 锚定 judge，掉分就
   fail build。
2. 按方言路由模型档位，难方言才配用贵的模型 —— A/B 实验证明轻 CoT
   对方言改写零帮助。
3. 诚实降级：上游抖了就说「这次启发式兜底了」，不装。

纯 Python 标准库后端，无构建前端，BYOK，历史只在浏览器。
