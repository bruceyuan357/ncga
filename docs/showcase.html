What it does

核心功能

一个把"标准化中文"重新染上地方色彩的写作 / 沟通工具 —— Grammarly 修拼写,NCGA 修"口音"。

🗣️

多方言改写

输入任意语言(中/英/日/法…),输出锁定为你选的中文方言。十种地域语体,从北京胡同到粤语书面、闽南汉字。

🎭

语境场景

同一句话,对长辈、对同事、在网上、在吐槽时说法不同。6 种场景调节口吻分寸。

⚖️

多方言对比

一次并排生成多个方言版本,直观看同一个意思在不同乡音里的差别。

🔍

AI 讲解

挑出改写里最有"方言味"的 3–6 处变化,逐条解释为什么这样写更地道。

⭐

质量评分 + 自我改进

对结果打分;当某方言长期低分,系统用 Reflexion 思路重写自己的"场景指引",越用越准。

📚

批量工作台

一次贴多行,并行改写,可排序、挑选、导出 CSV —— 给需要规模化处理的场景。

🏷️

品牌语调字典

自定义"原词 → 必须改成的词",强制注入,保证术语统一。

🌸

今日方言一句 · 随四时

每天一句谚语 × 十种乡音;UI 随春樱/夏绿/秋枫/冬青四季流转,带 24 节气与古诗轮换。

🧩

Chrome 扩展 code-complete

网页任意选中文字即可改写。两种模式:点选(右键挑方言)与即时(选中自动弹出)。Token 用 AES-GCM 本地加密。

💬

反馈表单

内嵌反馈入口,JSONL 落盘,IP 加盐哈希,0o600 权限 —— 收真实用户意见而不泄隐私。

How it stays native

关键机制:为风格而做的检索增强

不是训练模型,而是在每次改写时,把真实的"本地人怎么说"证据塞进提示词。改数据即时生效,无需重训。

RAG-for-style · 每次 /api/rewrite 的数据流

输入
你的文字任意语言,作为检索 query
→
检索 · 纯 stdlib BM25
句级 top-3 + 词级 top-5只在目标方言池里找最相似的
→
注入
【本地人示例】+【词音参考】拼进 system prompt
→
生成
带证据的方言输出不再凭描述脑补
「你今天看起来很漂亮」→词典递上 漂亮=嗲 · 你=侬→「侬今朝看起来老嗲额!」
Why it's well-built

值得说的工程结构

小,但每一处都为可维护、可信任、可分享而设计。

零运行时依赖

后端纯 Python 标准库(仅 certifi),前端原生 JS/CSS,无构建步骤。连方言检索都用手写 BM25,不引 PyTorch。clone 即跑。

单一真相源

方言/场景元数据只活在 presets.py,前端从 /api/presets 读取。加方言=改一个文件,前端自动同步。

优雅降级

LLM 挂了→本地启发式改写并明示降级;语料检索出错→照常改写。任何增强失败都不拖垮主路径。

纵深安全

CSP 无 unsafe-inline · 质量数据 AES-GCM 落盘 · 双轨认证(HMAC Cookie + Bearer)· 每 IP 限流 · 路径穿越拒绝 · HSTS。

两层测试

198 个离线单元测试(LLM 被 mock,秒级跑完)+ 14 项真实 LLM 冒烟脚本 —— 抓"协议变了"这类 mock 测不出的回归。

扩展隔离

Chrome 扩展用 Shadow DOM 渲染浮窗,宿主页 CSS 互不污染;token 仅以 AES-GCM 密文存于浏览器,passphrase 永不落盘。

  • 数据可编辑、可溯源 —— 400 句语料 + 1189 词条均带来源标注;改一行 JSONL、重启即生效。
  • 弱势方言收益最大 —— 粤语 / 闽南在通用模型里训练样本稀少,正是带出处的语料给它们提供真实依据。
  • 诚实的质量分级 —— 已核验 390 条、保留 10 条待母语者校对,绝不把没把握的标成"已验证"。
